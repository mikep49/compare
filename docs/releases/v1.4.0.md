## What's new

### Focus on the changes

- **Differences only** now works in the Document and Sheet views. It grays out unchanged lines and rows while keeping the pages and sheets whole.
- Changing comparison options keeps your place and the current change, so you can carry on reading.
- After **Clear**, click **Undo** in the message or press Ctrl+Z to bring the text or file back.

### Faster comparisons

- Long texts are compared in the background, and lines outside the visible area take less work to display.
- Code and spreadsheet comparisons now run in background workers, keeping the interface responsive while they finish.
- A progress message shows when a comparison is running, and results from canceled or replaced comparisons are discarded.

### More of the Windows backdrop

- The light and dark themes use Acrylic behind the sidebar and top bar on supported versions of Windows 11, showing more of what's behind the window.

## Fixes

- Files opened in different workspaces or on opposite sides no longer cancel each other's loads.
- When an opened file belongs in another workspace, it can no longer overwrite a newer file opened there. Switching workspaces while a file loads also keeps it in the right place.
- Spreadsheet rows containing separator characters are compared correctly instead of sometimes being treated as identical.
- Document patch exports preserve final newlines, blank-line whitespace, and changes hidden by the ignore options, so the patch reproduces the changed text exactly.
- CSV exports keep formula-like values and sheet names as text when opened in Excel.

## Download

- **Compare-Setup-1.4.0.exe** installs the app and adds *Send to → Compare* to Explorer.
- **Compare-Portable-1.4.0.exe** runs without installing.
