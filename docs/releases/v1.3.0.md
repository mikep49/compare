## What's new

### Code workspace
- A new **Code** item in the sidebar (Ctrl+3) compares source code the way GitHub shows a diff. Files moves to Ctrl+4.
- Switch between **Split** and **Unified** in the top bar; the choice is remembered.
- Changes come in hunks with three lines around each, under a header that names the function they're in. Expand folded lines 20 at a time, or unfold the whole file.
- Code is colored in GitHub's colors. The language comes from the file name, and pasted code is recognized by what it looks like.
- Changed words are marked, and each file's header counts the added and removed lines.
- F8, Find, swap, the ignore switches and *Send to → Compare* work as in the other workspaces.
- Export as an HTML report or as a patch that git applies.

### Updates from inside the app
- When a newer version is out, an **Update to x.x.x** button shows at the bottom of the sidebar.
- It downloads the new version in the background and checks its size and SHA-256 checksum. Then click **Restart to update**, or just close the app.
- Works for both the installed app and the portable exe.

### Text view
- Paragraphs now always sit beside their counterpart, however many blank lines are between them.
- Blank lines no longer count as differences, so texts that differ only in spacing are identical.

### Document and Sheet views
- The mouse wheel scrolls only the document or sheet it's over. Turn **Scroll together** on with the link button at the bottom right; the choice is remembered.

### Other
- Compare is now under the MIT license.
- A new [user guide](https://github.com/mikep49/compare/blob/main/docs/guide.md) covers every view, option and shortcut.
